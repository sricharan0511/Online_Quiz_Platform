# Online Quiz Platform

A Python-based quiz platform developed as part of my Python Development Internship at Pinnacle Labs.

## Project Description

This application allows users to create customizable quizzes and take saved quizzes through a simple and user-friendly interface.

Users can add questions with multiple-choice options, select the correct answer, save quizzes, and take them later. The application automatically calculates the score and percentage after completing a quiz.

## Features

- Create customizable quizzes
- Add multiple-choice questions
- Add four options for each question
- Select the correct answer
- Save quizzes for later use
- Select and take saved quizzes
- Automatic score calculation
- Percentage calculation
- Final result display
- User-friendly interface

## Technologies Used

- Python
- Tkinter
- JSON
